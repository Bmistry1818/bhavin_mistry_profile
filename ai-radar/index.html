ADOPT

Proven

Repo Agent Contracts (AGENTS.md & SKILL.md)

Version-controlled AGENTS.md build/architecture contracts and AAIF-standardized SKILL.md procedural bundles co-located inside enterprise repositories.

Rationale: Stops coding agents (Claude Code, Codex, Cursor) from guessing team conventions, enforcing deterministic test verification loops before PR creation.

Automated EvalOps in CI/CD

Automated regression testing of prompt templates, RAG ground truth, and reasoning chains in pull requests using golden SME benchmarks.

Rationale: Vibe-checking prompts in production is untenable in regulated environments; CI eval gates prevent silent degradation.

Model Context Protocol (MCP)

Standardized open protocol connecting AI agents securely to enterprise data sources (SQL, GitHub, Jira, Obsidian) with granular RBAC.

Rationale: Replaces brittle point-to-point tool integrations with a single composable interface supported across Claude, Cursor, and enterprise agents.

Enterprise Hybrid RAG

Hybrid sparse-dense retrieval with lexical BM25, semantic vector search, and cross-encoder reranking.

Rationale: Proven to achieve >90% factual retrieval accuracy in enterprise document search while keeping inference latency predictable and explainable.

Centralised LLM Gateways

Reverse-proxy routing layer providing unified multi-provider fallback, rate-limiting, semantic caching, and token budgeting.

Rationale: Essential for enterprise governance, eliminating hardcoded vendor API keys, and enforcing zero-data-retention compliance across engineering teams.

AI Coding CLI & IDE Agents

Context-aware terminal and IDE agents (Claude Code, Codex CLI, Cursor) operating within local git repositories.

Rationale: Delivers measurable developer cycle-time compression when coupled with rigorous CI linting, automated testing, and human code reviews.

TRIAL

Validated

Intelligent Model Routing & SLMs

Planner-Executor hierarchies routing 70-80% of high-volume extraction, classification, and routine coding to ultra-fast tiers (Gemini 4 Hydrogen, DeepSeek-V4.1-Flash, distilled Qwen4 FP8) while reserving Frontier planners (Claude Fable 5.2, GPT-6.2, Gemini 4 Carbon) for architectural reasoning.

Rationale: Captures the late-2026 80% flash inference cost collapse while cutting P95 time-to-first-token under 200ms and reducing single-provider vendor lock-in.

Sovereign Open-Weight Serving (vLLM & SGLang)

Self-hosting high-efficiency open weights (Qwen4, DeepSeek-V4, GLM-5.4 Loop Transformers, Kimi K3.1) inside private VPCs with vLLM/SGLang, FP8 quantization, and NVMe KV-cache offloading.

Rationale: Neutralizes cross-border data residency risk and frontier API price shock while achieving high-throughput serving across NVIDIA, AMD, and TPU silicon.

Agent2Agent Protocol (A2A) & Agentic Mesh

Horizontal peer-to-peer protocol allowing cross-vendor agents to discover capabilities via /.well-known/agent.json Agent Cards, negotiate tasks, and stream artifacts.

Rationale: Complements vertical MCP tool connectivity by preventing framework lock-in across specialized risk, coding, and operations agents.

GraphRAG & Entity Resolution

Augmenting vector embeddings with knowledge graph entity-relation trees (Neo4j / Graphiti) to resolve multi-document corporate relationships.

Rationale: Semantic vector similarity fails on tabular account numbers, product hierarchies, and cross-document dependency tracing.

Agentic Multi-Step RAG

Dynamic retrieval loops where agents decompose ambiguous questions, plan multi-hop searches, and critique intermediate outputs.

Rationale: Solves complex financial and analytical queries requiring data synthesis across multiple structured and unstructured sources.

Automated LLM Evaluation Harnesses

Continuous CI/CD eval pipelines (Ragas, DeepEval, Promptfoo) benchmarking ground truth, faithfulness, and latency before deployment.

Rationale: Replaces subjective vibe checks with empirical pass/fail thresholds in pull requests.

Automated AI Code Review Agents

Autonomous CI bots checking PRs against enterprise style guides, security postures, and architectural conventions.

Rationale: Reduces human review overhead on mundane checks, allowing senior engineers to focus on system design and business logic.

ASSESS

Spike

Formal Verification & Deterministic CI Gates

Pairing probabilistic LLM code synthesis with interactive theorem provers (e.g. Lean 4) and invariant property checks for memory-critical or Tier-1 regulated core modules.

Rationale: As autonomous coding agents raise PR volume exponentially, mathematical proof checks and deterministic fuzzing eliminate entire classes of security vulnerabilities before human review.

Computer-Use & GUI Agents

Vision-guided autonomous agents interacting directly with legacy desktop and web applications via keyboard/mouse emulation.

Rationale: Promising interface for legacy enterprise systems lacking modern APIs.

Hierarchical Multi-Agent Swarms

Multi-agent orchestration architectures (e.g. LangGraph supervisor-worker networks) coordinating specialised agent roles.

Rationale: Provides role separation between planning, execution, and verification.

WATCH

Early

Autonomous Agentic Payments

Autonomous software agents authorized to execute programmatic financial transfers, invoices, or settlements.

Rationale: Emerging standard in digital treasury and automated merchant settlements in regulated markets.

Autonomous Production Deployments

End-to-end agents writing code, merging PRs, and deploying directly to customer-facing production infrastructure without human sign-off.

Rationale: Theoretical limit of software engineering automation.
